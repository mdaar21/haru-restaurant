# HARU | هارو

موقع مطعم هارو ومنيو تفاعلي بالعربية والإنجليزية.

[فتح الموقع](https://mdaar21.github.io/haru-restaurant/)

## Features

- Arabic and English, with saved language preference.
- Dark Haru identity, original logo and transparent food photography.
- 48 menu items, bilingual search, category filters and price sorting.
- Saved picks displayed in the menu grid; +/check toggles stay in place.
- Restaurant location, reservations and Instagram links.

## Hosting

Static HTML, CSS and JavaScript; no build step. GitHub Pages serves the main branch root. Serve this directory through any static HTTP server for local preview.

Menu data: `menu.json`. Interface: `index.html`, `app.js` and the CSS files. Assets and font licenses: `assets/`.
